# Security Policy

## Supported Versions

Security fixes are provided for the latest published `@picr/react-grid-gallery`
release. The original `react-grid-gallery` package is not covered by this
fork's policy.

## Reporting a Vulnerability

Use GitHub's
[private vulnerability reporting](https://github.com/IsaacInsoll/react-grid-gallery/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected version, impact, reproduction steps or a minimal example,
and any suggested mitigation. Please allow time for the report to be reviewed
and coordinated before public disclosure. No personal email address or fixed
response-time commitment is provided.
